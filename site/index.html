01

the question

Does a network really beat a well-built classic pipeline?

Mapping farmland, forest, roads and cities from satellite images is routine work in remote sensing. Two approaches compete. In the classic one, a person decides what to measure in each image (colour, texture, edges) and a model like a Random Forest learns from those numbers. In the deep one, a convolutional network reads the raw pixels and finds its own features.

Both are used in practice, and the network usually wins. I wanted to know by how much, where the gap comes from, and whether the answer holds up under a proper statistical test rather than one lucky split.

The data is EuroSAT-RGB: 27,000 patches of 64×64 pixels cut from Sentinel-2 images over Europe, each labelled with one of ten land-use classes.

  • AnnualCrop3,000
  • Forest3,000
  • HerbaceousVegetation3,000
  • Highway2,500
  • Industrial2,500
  • Pasture2,000
  • PermanentCrop2,500
  • Residential3,000
  • River2,500
  • SeaLake3,000
02

the approach

One fair comparison, three models

Same data, same folds

Each class is split evenly across 5 folds. Every model is trained on four folds and tested on the fifth, five times over, so every patch is predicted exactly once by every model.

Classic route: 87 hand-crafted numbers

Colour statistics, colour histograms, texture measures (GLCM), shape moments, an edge-density count and a vegetation index (VARI). Random Forest and XGBoost learn from these.

Deep route: ResNet-18

A network pretrained on ImageNet, fine-tuned on the patches. It gets the pixels and nothing else.

Then look inside

SHAP shows which features the tree models rely on. Grad-CAM and occlusion tests show which image regions the network relies on.

9× fewer errors

ResNet-18 mislabels 280 patches. XGBoost mislabels 2,614.

Not a lucky split

Every pairwise gap is significant under a paired bootstrap and McNemar's test, with Holm correction.

Calibration flips

XGBoost's confidence is the most honest of the three. Random Forest's is the least.

Where the gap comes from. Most classes are easy for every model. Highway is the exception: the classic models find it hard, and the network does not.

Reading ECE. When a model says "90% sure", how far is that from how often it is right? ECE averages that gap, so lower is better. Random Forest is off by about 11 points on average, XGBoost by about 2.

Importance methods do not always agree. Permutation importance on the same forest ranks colour histograms first (50.1%) and texture third (16.4%), because correlated features share credit differently. Treat the ranking as a hint, not a verdict.

The network looks at the object that defines the class. Grad-CAM paints the regions that pushed the network towards its answer. Red titles mark mistakes.

Occlusion is a second, independent check: hide one square of the image at a time and see how much the answer suffers.

05

honest limits

What this does not show

  1. RGB only.The near-infrared and shortwave bands that make vegetation and water easy to separate are not used.
  2. Europe only.EuroSAT covers European landscapes; nothing here says the models transfer to the tropics or deserts.
  3. One snapshot per patch.Time series, which are Sentinel-2's main strength, are ignored.
  4. One network.A newer architecture would probably score higher. The point here is classic versus deep, not the best network.
  5. Explanations are evidence, not proof.Grad-CAM and SHAP are approximations, and they come from a single fold.
06

reproduce it

A few commands, no manual setup

git clone https://github.com/gstvschlz/land-classification
cd land-classification
mise trust            # allow the repo's mise.toml
mise install          # pins Python 3.12 and uv
mise run setup        # installs the locked dependencies
mise run smoke        # end-to-end check, a few minutes
mise run all          # the full study

You only need mise installed. It downloads the pinned Python and uv, and the pipeline downloads the dataset itself (95 MB, checksum-verified).

How long it takes. The full study took about 80 minutes on a laptop with an RTX 5090 GPU. ResNet-18 is most of that, at roughly 10 minutes per fold. On a CPU expect many hours.

TaskWhat it does
mise run downloadFetch EuroSAT, write the 5-fold split
mise run featuresCompute the 87 hand-crafted features
mise run train-traditionalRandom Forest and XGBoost
mise run train-resnetFine-tune ResNet-18
mise run explain-traditionalFeature importance and SHAP
mise run explain-cnnGrad-CAM and occlusion maps
mise run evaluateMetrics, tests and figures
mise run checkSanity-check the feature extractor
mise run sitePreview this page locally

Every hyperparameter and the random seed live in configs/default.yaml. The numbers on this page come from one run of mise run all with that file, so a rerun on the same setup should match closely. GPU kernels are not bit-for-bit deterministic, so expect small differences in the last digit.
